# Leogix website

Static site for Leogix (parent brand).

- `index.html` — homepage (Hero B: autopilot switch + moving work cards)
- `hero-a.html` — alternative hero (dot-grid L)
- `v5/` — current version: v4 with all its motion, plus a live product stage (Sales, Ask, Support) and a working contact form
- `v2/`, `v3/`, `v4/` — earlier versions, kept for reference

No build step. Deploy on Vercel with the "Other" preset and no build command.
