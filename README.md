# Leogix website

Static site for Leogix (parent brand).

- `index.html` — homepage (Hero B: autopilot switch + moving work cards)
- `hero-a.html` — alternative hero (dot-grid L)
- `v6/` — current version: light, built around Leo (a live 3D form that reacts to the cursor and to a sample call), rewritten copy, v4's scroll motion kept. Uses footage from `v5/media/`
- `v5/` — previous version: v4 with all its motion, plus a live product stage (Sales, Ask, Support) and a working contact form
- `v2/`, `v3/`, `v4/` — earlier versions, kept for reference

No build step. Deploy on Vercel with the "Other" preset and no build command.
